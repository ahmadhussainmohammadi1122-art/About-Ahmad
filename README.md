# Ahmad Hussain Mohammadi — Personal Portfolio

A bold, responsive personal portfolio introducing my background, skills, learning journey, and projects as an aspiring software developer.

## Built with

- HTML5
- CSS3
- Vanilla JavaScript

## Features

- Responsive layout for desktop, tablet, and mobile
- Mobile navigation menu
- Smooth scrolling and subtle scroll-reveal effects
- Reduced-motion accessibility support
- Skills, education, journey, project, and contact sections
- No framework or build tools required

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.

## Before publishing

- Replace `YOUR_EMAIL@example.com` in `index.html` with the email address you want to share.
- Replace the generic GitHub and LinkedIn links with your own profiles.
- Review every biography detail and edit anything that does not accurately represent you.
- Add a profile photo or certificate images to `assets/` only if you want to make them public.
- Check the site on both desktop and mobile.

## Future improvements

- Add more completed projects with live demos and source links.
- Add project screenshots.
- Connect the portfolio to GitHub Pages.
